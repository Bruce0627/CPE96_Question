# CPE56 C++ 題解

收錄 [CPE56 官方選集](https://cpe.mcu.edu.tw/cpelist.php) 的全部 56 題。每個程式都能獨立編譯，以標準輸入讀取 UVa 測資。

## 在 Windows 的 VS Code 執行

1. 開啟 `CPE56.code-workspace`，再從 `solutions` 開啟要練習的 `.cpp`。
2. 按 `Ctrl+Shift+B` 編譯目前題目。要編譯並執行，按 `Ctrl+Shift+P`，選 **Tasks: Run Task**，再選 **CPE56: 編譯並執行目前題目**。
3. 在 VS Code 終端機貼上測資。讀至 EOF 的題目可按 `Ctrl+Z`，再按 Enter 結束輸入。

編譯需要 PATH 上的 `g++`，專案使用 C++17。提交時可直接複製單一 `.cpp` 的內容。
